# Program Memprediksi Jarak Dari Mobil

Membuat Program Memprediksi Jarak dari Mobil menggunakan Model Linear Regression secara manual tanpa library sckit-learn

### Membuat VirtualEnvironment

```bash
python3 -m venv ./venv
```

### Aktifkan VirtualEnvironment

```bash
source .venv/bin/activate
```

### Install Pakages

Install library yang dibutuhkan supaya bisa jalankan dengan baik

```bash
pip install -r requirements.txt
```

### Run Program

```bash
python3 main.py
```
